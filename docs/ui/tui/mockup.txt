TUI orb reference mockup -- docs/ui/tui/mockup.txt
Counterpart of docs/ui/mockup.html. It is monochrome text by definition: no
color, no animation. Every frame is a literal capture and renders 1:1 in a
terminal of the stated size.

Conventions in this file:
  '_'   marks the cursor: the text cursor in the composer, or the streaming
        cursor at the end of an assistant row still receiving deltas.
  '#' / '-'  are the filled and empty cells of the level meter. In the real
        TUI the fill is reverse-video or a color pair; here it is text.
  '^T'  means Ctrl+T (and so on). Curses draws '^' for the control key.
  Attributes (A_BOLD / A_DIM / A_REVERSE) and color pairs are an enhancement
        and are not visible in a plain text capture; see tokens.md for the
        mapping and the always-present non-color cue.
